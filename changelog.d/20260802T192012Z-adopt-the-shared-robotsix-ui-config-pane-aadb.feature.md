Adopt the shared `@robotsix/ui` v0.1.6 ConfigPanel as the settings UI, replacing the bespoke field/history/tab renderer in `board-mill.js`. The panel is JSON-Schema-driven with typed inputs, `writeOnly` secret masking, merge-on-write, and version history with rollback — served as vendored vanilla JS/CSS (no bundler). Also fixed the secret-write deviation: `PUT /config` now accepts secret keys with merge-on-write semantics (blank/masked keeps the stored value; an explicit typed value overwrites), writing them to the `secrets` block of `config.json`.

The implement stage's summary-verification gate no longer blocks tickets over claims that were never file claims. It read any backticked span as a path, so `GET /wallet/value` and `uv export --format cyclonedx1.5 -o sbom.cdx.json` were checked for on disk and, being absent, blocked work that had actually landed; a span containing whitespace is now a command or a route, not a path. It also matched its trigger verbs inside hyphenated compounds — "glibc-generated lockfile" counted as a claim to have generated something — and let a verb bind to a path up to eighty characters away, across sentence and clause boundaries, so an unrelated filename in the next sentence became the object of an earlier "created". Verbs no longer match mid-compound and the gap no longer crosses `.`, `;` or an em dash. Three further cases could never pass: a gitignored path, which by definition cannot appear in a diff; a directory, which `--name-only` never names; and a changelog fragment the summary reports *deleting*, where the tidy-up itself was flagged as a hallucinated file.

The resume-with-ahead edit-claim guard no longer blocks a ticket whose branch already carries committed work. It required *every* claimed edit to appear in the branch diff, so a single stray path — a changelog fragment a later pass renamed away, a file written then reverted — stranded the whole implementation in BLOCKED. It now blocks only when the branch carries no commits at all, which is the shape the guard was written for, and logs the absent paths when it lets a populated branch through.

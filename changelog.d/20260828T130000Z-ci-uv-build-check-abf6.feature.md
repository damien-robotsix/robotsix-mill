CI now builds the sdist and wheel on every pull request, and asserts the wheel actually ships its force-included resources. `uv sync` installs from the live source tree, so nothing in CI exercised Hatchling's packaging: the first real build was the Docker image in `release.yml` — post-merge and post-tag. A stale `[tool.hatch.build.targets.wheel.force-include]` entry (a renamed or deleted `agent_definitions` / `expert_definitions` / `skills` / `contrib/completions`) therefore escaped every pre-merge gate. `scripts/check_wheel_contents.py` reads the expected targets from the force-include table rather than hardcoding them, so a newly bundled directory is covered as soon as its entry is added.

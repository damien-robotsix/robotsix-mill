Fix `publish-mill` Docker build failure in the `ui` stage caused by esbuild lacking a musl binary on alpine.  The `@robotsix/ui` lockfile was generated on glibc and omitted `@esbuild/linux-x64-musl`, so `vite build` (triggered by the `prepare` script during `npm install` from git) failed on `node:22-alpine`.  The fix runs the git install with `--ignore-scripts`, then re-resolves dependencies without the lockfile inside the package directory so npm picks up platform-appropriate esbuild, then builds explicitly.

Move periodic agent scheduling interval from global config to per-agent YAML definitions. Each agent's base YAML (`agent_definitions/periodic/<name>.yaml`) now declares its own cadence (`interval: 14d`) — the previous default of 14 days is preserved. Per-repo overlays (`.robotsix-mill/periodic/<name>.yaml`) can override per repository. Resolution order: overlay > base YAML > Settings fallback. The legacy `*_interval_seconds` config keys remain as a fallback for bespoke agents that don't declare an interval.

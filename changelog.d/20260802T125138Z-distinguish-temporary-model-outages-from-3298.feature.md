The worker now detects LLM-provider model outages ("model unavailable", "overloaded", "no healthy endpoint") and parks affected tickets without consuming retry budget, mirroring the existing network-outage and disk-full parks. A configurable `model_outage_max_parks` ceiling (default 20) prevents infinite parking when the outage is permanent (e.g. a bad model id). The run-health digest now surfaces model-outage signals distinctly as infrastructure anomalies rather than work blockers.

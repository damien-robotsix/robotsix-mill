Fix `GET /tickets?created_after=...` filter: naive ISO-8601 datetimes (e.g. `2020-01-01T00:00:00`) are now treated as UTC instead of raising a `TypeError` inside the ORM layer. The list endpoint also now skips individual tickets whose enrichment fails (e.g. a row with NULL `created_at`) instead of 500-ing the whole board — the bad row is logged and the remaining tickets are returned.

Bump the `robotsix-http` override pin to pick up the `_drive_sync` running-loop fix, and `robotsix-llmio` in step with it. The library's sync `call_with_retry` called `asyncio.run()` unconditionally, so `robotsix-github-auth` — which mill uses to mint installation tokens — raised `RuntimeError: asyncio.run() cannot be called from a running event loop` whenever a token was minted from an async agent tool. `robotsix-github-auth` re-raised it as `TokenMintError`, which `forge.auth.classify_token_error()` classifies as **permanent**, so every bridged `git_push_with_lease` / `git_fetch` / `fetch_ci_logs` failed deterministically with no retry and blocked the ticket. The llmio bump is required with it: robotsix-http 0.3.2 renamed `_compute_backoff` to the public `compute_backoff`, which only llmio `13a53e48` onward imports.

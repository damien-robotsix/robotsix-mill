`extra_sandbox_packages` pip entries are now installed ONCE into the shared disk-backed sandbox cache (`<cache>/pip-extras/py<X.Y>/<hash>`, marker-guarded, race-safe) and exported on `PYTHONPATH`/`PATH`, instead of `pip install --user` into the container's tmpfs on EVERY `run_command`. Live on 2026-08-29 that per-call install cost ~7 s on top of a 0.7 s container (robotsix-mill declares `pip:pytest`/`pip:pytest-asyncio`) — ~36 h/week across 16k trivial agent commands.
